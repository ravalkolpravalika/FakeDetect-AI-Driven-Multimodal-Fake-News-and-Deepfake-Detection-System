1. Hardware Requirements 
• Processor: Intel Core i5/i7 (11th Gen or above) or AMD Ryzen 5/7 equivalent 
• GPU: NVIDIA GPU with CUDA support (e.g., GTX 1650 / RTX 3050 or above) - 
optional but recommended 
• RAM: Minimum 8 GB (16 GB recommended) 
• Storage: Minimum 256 GB SSD (512 GB SSD recommended) 
• System Type: 64-bit Operating System, x64-based processor 

2. Software Requirements 
• Operating System: Windows 10/11 (64-bit) or Ubuntu 20.04+ 
• Programming Language: Python 3.8 or above 
• IDE / Environment: Jupyter Notebook, Visual Studio Code, or Google Colab 
• Deep Learning Framework: PyTorch 
• CNN Architecture: TorchVision (EfficientNetB0) 
• NLP Library: HuggingFace Transformers (bert-base-uncased), NLTK 
• Image and Video Processing: OpenCV (cv2), PIL / Pillow 
• Data Handling: Pandas, NumPy 
• Machine Learning Library: Scikit-learn 
• Explainability: pytorch-grad-cam (Grad-CAM) 
• Visualisation: Matplotlib, Seaborn 
• Frontend / Deployment: Streamlit 
• Cloud Storage: Google Drive 

3. Dataset Requirements 
• Fake and Real News Dataset - 44,898 labelled news articles (Fake.csv + True.csv) - 
used for BERT training 
• LIAR Dataset - 12,836 political statements (train.tsv, valid.tsv, test.tsv) - used as 
secondary text dataset 
• Deepfake vs Real 60K - 190,335 face images - used for CNN image training 
• 140K Real and Fake Faces - 140,000 StyleGAN and real face images - used to 
improve AI-generated face detection 
• AI-Generated vs Real - 48,000 diverse AI-generated and real images - used to extend 
CNN generalisation 
• Real/Fake Video Dataset - 872 video clips - used for video deepfake detection fine
tuning
